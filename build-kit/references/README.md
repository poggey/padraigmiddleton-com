# References

Put screenshots here of specific things you like. Claude Code reads images, so a screenshot of exactly the detail you mean is worth more than any description.

## What to collect (about 10 to 15 images)

Crop each screenshot to the element, not the whole page. Name files so the intent is obvious.

| Suggested file name | What to capture |
|---|---|
| `stripe-bento-cards.png` | A Stripe card that contains a miniature live interface (for example the billing meter card) |
| `stripe-layering.png` | Any Stripe section where cards overlap or sit on each other |
| `stripe-hero-graphic.png` | The animated hero graphic, mid-animation |
| `stripe-stats.png` | Stripe's row of big figures, to show how sparingly numbers are used |
| `apple-nav-glass.png` | Apple's frosted navigation bar over a busy image |
| `apple-section-spacing.png` | One Apple section showing how much space surrounds a single idea |
| `supabase-product-tiles.png` | The product tiles, each with its own small graphic |
| `supabase-tabs.png` | The dashboard tabs that switch the preview |
| `type-you-like.png` | Any site whose typography you love, with a note on what you like |
| `chart-you-like.png` | A chart from FT, The Economist, Bloomberg or similar that you think is beautifully clear |
| `dont-like-*.png` | Anything you specifically do not want (for example `dont-like-raycast-gloss.png`) |

## Add a note to each

Create `notes.md` in this folder with one line per image: what you like about it and what Claude Code should take from it. For example:

- `stripe-bento-cards.png`: the card shows the real product working, small. I want my project cards to do this with my own charts.
- `apple-nav-glass.png`: subtle blur, thin border, nothing heavy. Only for the nav and a few floating cards.

## Important

These are for inspiration only. Claude Code must take the principle, never copy a design.
